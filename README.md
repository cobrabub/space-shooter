# 🚀 Space Shooter

Un jeu de tir spatial classique construit en **HTML5 / CSS3 / JavaScript** — pur, sans dépendances, prêt à jouer dans n'importe quel navigateur !

![Space Shooter](https://img.shields.io/badge/HTML5-Game-orange) ![No Dependencies](https://img.shields.io/badge/Dependencies-None-green) ![License](https://img.shields.io/badge/License-MIT-blue)

## 🎮 Comment jouer

1. Ouvre `space-shooter.html` dans ton navigateur
2. Joue !

### Contrôles
| Touche | Action |
|--------|--------|
| ⬅️ / ➡️ ou `A` / `D` | Déplacer le vaisseau |
| `Espace` | Tirer |
| `P` | Pause |

## ✨ Fonctionnalités

- 🎯 Système de tir et de collisions
- 👾 Vagues d'ennemis
- 📈 Score et niveaux de difficulté progressifs
- 💥 Effets visuels
- 📱 Compatible desktop

## 🛠️ Technologies

- **HTML5 Canvas** pour le rendu
- **JavaScript** vanilla (aucun framework)
- **CSS3** pour l'interface
